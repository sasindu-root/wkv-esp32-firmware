
# BC2_U1 Firmware Releases

This directory is reserved for approved BC2 Unit 1 firmware release files.

Firmware files must be compiled for the correct NORVI AE04-V / ESP32 configuration and tested before release.

Release files will use versioned filenames, for example:

- `bc2_u1_v1.0.0.bin`
- `BC2_U1_1_0_0.ino.bin` (1.0.0, not yet approved)

Do not upload source code, Wi-Fi passwords, API credentials, or other secrets here.

The current approved version is controlled by `../manifest.json`.
